# 长时间稳定性测试说明

适用章节：`5.3.6 长时间稳定性测试`

## 一、推荐测试口径

- 并发用户数：`100`
- 持续时间：`2 小时`
- 业务比例：
  - `70%` 学习进度上报
  - `20%` 课程详情查询
  - `10%` 评论发布

## 二、脚本文件

- JMeter 测试计划：`server/test/jmeter/scenario6_soak_mixed_rw.jmx`
- 指标采样脚本：`server/test/jmeter/collect_soak_metrics.ps1`
- 一键执行脚本：`server/test/jmeter/run_soak_test.ps1`
- JMeter 结果分析脚本：`server/test/jmeter/analyze_soak_results.py`

## 三、执行前准备

1. 确认后端服务可访问：`http://127.0.0.1:3000`
2. 确认测试数据存在：
   - `server/test/jmeter/data/users.csv`
   - `server/test/jmeter/data/videos.csv`
3. 确认 Docker 组件已启动：
   - Redis
   - RabbitMQ
   - MySQL
4. 如需测试默认业务稳定性，不要开启 `DISABLE_COURSE_LIST_CACHE=true`
5. 如需避免性能测试被限流干扰，可临时提高限流配置

## 四、执行命令

```powershell
cd server\test\jmeter

.\run_soak_test.ps1 `
  -JMeterBin "D:\Document\apache-jmeter-5.6.3\apache-jmeter-5.6.3\bin\jmeter.bat" `
  -DurationHours 2 `
  -SampleEverySec 300 `
  -RedisContainer redis `
  -RabbitMQContainer rabbitmq `
  -MySQLContainer mysql
```

## 五、回填建议

- `results/soak_all.csv` 用于分析平均 RT 与错误率
- `results/soak_metrics.csv` 用于回填：
  - Redis 内存占用
  - MySQL 连接数
  - RabbitMQ 消息积压数
  - 服务端进程内存
