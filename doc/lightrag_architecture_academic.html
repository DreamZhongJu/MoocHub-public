（1）实时问答链路

前端页面

课程详情页、文章详情页发起问答、总结与练习题请求

Go 业务服务

完成权限校验、参数解析与课程 / 文章范围约束

Python 微服务

封装 LightRAG Query 能力并执行检索增强生成

结果返回

返回回答内容、相关实体及引用来源

（2）知识同步链路

知识源

课程文本、视频转录文本、文章正文内容

Go 业务服务

在视频上传、文章发布等场景下触发知识同步事件

RabbitMQ

承担异步消息投递，实现知识同步与主业务链路解耦

Python 微服务

消费同步事件，执行 Ingest 任务并调用 LightRAG 入库

（3）LightRAG 核心处理

文档入库

对课程与文章文本进行统一组织与知识源抽取

索引构建

完成实体关系抽取与图检索索引构建

检索增强生成

支持问答、课程总结、要点提炼与练习题生成

该架构采用 Go 业务服务与 Python 智能微服务解耦的集成方式，通过 RabbitMQ 实现知识同步异步化， 通过 HTTP 实现实时查询调用，并结合课程或文章的业务范围约束，使 LightRAG 智能辅助能力能够围绕当前学习内容开展定向知识服务。
