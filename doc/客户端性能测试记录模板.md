- 推荐使用 **真机** 进行最终测量，不建议使用模拟器作为论文定稿数据来源。
- 推荐工具：Flutter DevTools（Performance / Memory 两个面板）。
- 每个页面建议至少重复测试 3 次，取平均值。
- 若页面存在明显卡顿，应如实记录 `Jank` 与首帧峰值，不要人为平滑。

## 二、页面测试步骤模板

### 1. 首页滚动

- 进入首页，等待首屏完全加载。
- 连续上下滑动 30 秒。
- 记录：
  - 平均帧率
  - 最低帧率
  - 内存峰值
  - 是否出现 Jank
  - 首次加载阶段最长帧耗时

### 2. 视频播放

- 进入视频详情页。
- 连续播放 60 秒，并拖动进度条 3 次。
- 记录：
  - 平均帧率
  - 最低帧率
  - 内存峰值
  - 是否出现 Jank

### 3. 聊天消息列表

- 进入聊天会话列表与会话详情页。
- 连续滚动消息 30 秒，并发送 3 条消息。
- 记录：
  - 平均帧率
  - 最低帧率
  - 内存峰值
  - 是否出现 Jank

### 4. 课程详情（含评论）

- 进入课程详情页。
- 浏览课程简介、视频列表与评论区，连续滚动 30 秒。
- 记录：
  - 平均帧率
  - 最低帧率
  - 内存峰值
  - 是否出现 Jank

## 四、论文撰写提示

可直接参考以下句式填写论文：

1. **整体流畅性描述**

> Flutter 框架以 60fps（部分设备为 120fps）为渲染目标，当单帧耗时超过 16ms（或 8ms）时会产生卡顿。由测试结果可见，______、______ 等页面平均帧率稳定在 ______fps 附近，能够满足移动端流畅交互要求。

2. **首帧峰值分析**

> 页面在首次加载时出现约 ______ms 的帧耗时峰值，主要原因是 ______。通过 ______ 优化后，页面平均帧率提升至 ______fps，卡顿现象得到缓解。

3. **问题记录**

> 在持续滚动或复杂组件同时渲染场景下，首页推荐列表 / 课程详情长内容区域仍存在一定程度的 Jank，后续可通过进一步控制图片解码尺寸、减少重绘范围以及分段渲染长文本的方式继续优化。
