三、LightRAG 检索与生成

增强生成结果

输出回答正文、相关实体、引用来源与原始检索信息

四、两条核心业务流程

知识同步流程

1
教师上传视频或管理员发布文章后，Go 服务端生成知识同步事件。
2
RabbitMQ 异步投递事件，Python 微服务消费后触发 Ingest 任务。
3
LightRAG 对文本进行入库、实体关系抽取与图索引构建。

智能问答流程

1
用户在课程详情页或文章详情页发起 AI 问答、总结或练习题生成请求。
2
Go 服务端根据 course_id 或 article_id 构造带业务范围约束的查询请求。
3
Python 微服务调用 LightRAG 完成检索增强生成，并返回答案、实体及引用来源。
设计要点：系统采用 Go 业务服务与 Python 智能微服务解耦架构，利用 RabbitMQ 完成知识同步异步化， 利用 HTTP 完成实时问答调用；通过业务范围约束机制，使智能辅助结果优先围绕当前课程或文章内容展开， 体现面向具体学习场景的 LightRAG 集成能力。
