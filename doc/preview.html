请求到达
TraceIDMiddleware ← 生成 / 透传 X-Trace-Id
GlobalRateLimitMiddleware ← IP 级全局限流（300次/分钟）
CORS ← 跨域白名单
CustomLogger ← 结构化日志 + 采样
Recovery ← panic 恢复 + 堆栈打印
[Auth 路由]
→ AuthRateLimit (40/min) → Handler
[写操作]
→ WriteRateLimit (120/min) → IdempotencyMiddleware → AuthMiddleware → Handler
[Admin 路由]
→ AuthMiddleware → RoleMiddleware ("admin") → Handler
