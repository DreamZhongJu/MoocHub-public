# MoocHub

MoocHub 是一个跨平台移动端在线学习社区项目（Flutter 客户端 + Go 后端）。当前代码基于电商项目迁移而来，前端仍保留商品列表/购物车/商品详情等页面，后端仍以商品、分类、购物车为核心模型。本 README 先给出项目简介，并提供一个按“改造顺序”排序的 TODO 清单，便于你按步骤完成从电商到 MOOC 的系统化重构。

## 项目简介
- 目标：提供视频播放、文章阅读、评论互动、学习进度、积分体系等核心能力的在线学习社区 App。
- 客户端：Flutter（`flutter/`），目前主要是电商页面与路由结构（`Home/Category/Cart/User` + 商品详情）。
- 服务端：Go + Gin + Gorm（`server/`），目前是商品/分类/购物车/后台管理接口。
- 数据库：MySQL（当前模型为 `products/categories/cart/users` 等）。
